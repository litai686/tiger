核心能力

不止会聊天，它真的会把活干完

回合循环、工具、上下文管理、权限与撤销都在服务端完成；桌面端只负责让你看得清、控得住。

自主 Agent 循环

观察 → 规划 → 执行 → 校验。空输出重试、重复调用检测、假完成检测，长任务不会莫名中断。

27 个内置工具

27 个内置工具覆盖 bash、view / edit / multiedit、grep / glob、todos、job_output 与 8 个 LSP 工具；另有子代理、recall 与动态 MCP 工具。

LSP 代码智能

8 个 LSP 工具：诊断、定义、引用、调用层级、跨文件重命名与按符号修复，直接对接项目自己的语言服务器。

Skills 按需加载

内置 skill 随二进制分发，仓库级 skill 放在 .agents/skills/，同一套流程写一次、跨会话复用。

MCP 生态直连

接入任意 MCP 服务器；工具 JSON Schema 原样透传，$ref 与组合关键字不会丢，参数不缺不坏。

长上下文不崩

自动压缩 + 确定性事实块 + 归档编号 #N，需要时用 recall 取回细节，128k 窗口也能跑完整段重构。

每轮可撤销

git 仓库里每轮开始前保存工作树快照，一键回退本轮改动；非 git 目录会提前提示，不会让你误以为能回滚。

多会话并行

可选开启同目录多会话并行（最多 3 个），进程级文件写锁 + 读后写守卫，互不覆盖。

模型自由 + 模型管理

任意 OpenAI 兼容接口：云端 API、llama.cpp、Ollama、vLLM 都行；独立「模型管理」TAB 增删改 provider，云端模型改完无需重启。

项目浏览与差异

「项目管理」TAB 用懒加载文件树浏览工作区，右侧「预览 / 差异」双 TAB；有 Git 变更的文件直接看差异并暂存，双击即可跳转。

源码管理视图

VSCode 风格的「源代码管理」：分支、提交信息、更改 / 已暂存与提交图一屏完成；split / unified 差异、子目录仓库与 SSE 自动刷新。

交互终端

「终端」TAB 内嵌 xterm.js：服务端本机 PTY 或 terminal-targets.json 里的 SSH 目标，支持接管控制与只读模式，也能查看 Agent 后台作业输出。

可控与可扩展

PreToolUse hooks 在执行前拦截或改写工具调用；决策模式输出 choice / bool / score 结构化结果；权限请求与 bash 只读白名单兜底。

连接与认证

TCP 默认 TLS 1.3，客户端用 ECDSA P-256 指纹钉住服务端，并以 Bearer token 认证；/admin/ 可生成、删除 token 并查看活跃连接，--rotate-token 可整体轮换。

全平台 + 自动更新

Windows 安装包、macOS dmg、Linux deb / AppImage；桌面端应用内检测新版本、后台下载、提示升级。

分离设计

Agent 与界面，本来就是两件事

服务端负责「做事」，桌面端负责「让人看清、控住」。桌面端不打包、不启动服务端； 服务端不依赖桌面端，也不渲染界面。两端各自构建、各自升级，只通过一条加密连接通信。

服务端 · 单个 Go 二进制

Agent 运行时

  • 回合循环、27 个内置工具、LSP / MCP / Skills
  • 上下文压缩、recall、每轮撤销
  • 会话、workspace、配置与快照持久化
  • 权限、hooks、token 认证与 /admin/

不渲染界面，也不依赖桌面端在线。

HTTP API + SSE · TLS 1.3 + 指纹 pin + Bearer token
桌面端 · Tauri 2

纯 UI 操作台

  • Agent 对话、工具调用与差异可视化
  • 模型管理、项目管理、源码管理
  • 交互终端（本机 PTY / SSH 目标）
  • 技能、设置、硬件与连接状态

不打包、不启动服务端，不执行 Agent 工具，不持久化会话。

01

算力放在合适的机器

服务端可以跑在本机、局域网工作站或远端服务器；桌面端只负责显示与操作，底部硬件栏展示的是服务端硬件。显卡与内存优先留给模型和工具。

02

独立构建，独立升级

服务端是单个 Go 二进制，桌面端是 Tauri 应用：服务端更新不必重新打包桌面端，桌面端升级也不打断运行中的服务端；安装包不内嵌服务端与 Go 运行时。

03

一个服务端，多台设备

会话、workspace、配置与撤销快照都留在服务端；每台设备用一条连接串接入，token 在 /admin/ 按需增删，换电脑可以接着同一批会话。

04

UI 只是入口，不打断回合

回合循环、工具执行、压缩与撤销都在服务端完成；桌面端切换页面或短暂重连，不会重启或取消服务端上的回合。

05

安全边界集中在服务端

Agent 工具只在服务端执行；权限请求、bash 只读白名单、hooks、工作区包含性校验由服务端统一执行；交互终端同样运行在服务端，TCP 强制 TLS 1.3 + 指纹 pin + Bearer token。

06

唯一契约，天然可集成

两端只通过 HTTP API + SSE 通信；CLI、脚本或你自己的客户端可以复用同一套接口，Swagger 在 /v1/docs/。

协作方式

一条加密连接，两个独立进程

两端只通过 HTTP API + SSE 通信：桌面端把操作发给服务端，服务端把事件流推回。 连接串把地址、指纹与 token 合并成一次粘贴，算力与界面因此可以分开部署。

常见问题

上手之前，你可能想知道

Tiger Agent 是什么？
服务端 / 桌面端分离的 AI 编码助手。Go 服务端是 Agent 运行时，负责回合循环、工具执行、权限与会话持久化；Tauri 桌面端是纯操作台，提供 Agent、模型管理、项目管理、源码管理、终端、技能与设置 7 个视图。它能读代码、改文件、运行命令、跑测试、按符号修复，并把每一步都留在你自己的机器上。
为什么要把服务端和桌面端分开？
因为 Agent 运行时与操作界面是两件不同的事：回合循环、工具执行、权限与持久化需要长期驻留并独立升级，适合放在服务端；对话、项目、源码与终端更适合桌面交互。拆开后，服务端可以放在算力更强的机器或远端服务器，桌面端保持轻量；两端各自发布、互不拖累，同一个服务端还能被多台设备通过各自 token 接入。
必须使用本地模型或独立显卡吗？
不需要。它接受任意 OpenAI 兼容接口：可以直接接云端 API，也可以接本机的 llama.cpp、Ollama、vLLM 等推理服务。是否使用显卡取决于你选择的模型。
代码和数据会被上传吗？
服务端、工具与文件读写都在本机执行，只有模型请求会发给你自己配置的模型服务。桌面端连接服务端使用 TLS 1.3，并用 ECDSA P-256 指纹钉住服务端身份，请求还需携带 Bearer token；token 可在 /admin/ 管理界面生成与删除。
「终端」和「源码管理」能做什么？
终端是服务端上的交互 PTY（xterm.js），默认在服务端主机执行，也可在 terminal-targets.json 里配置 SSH 目标；同一页还能查看与终止 Agent 的后台作业。项目管理用于浏览文件与查看差异，源码管理提供暂存、提交信息、提交图和 split / unified 差异，二者都走服务端 Git 接口。
可以把服务端放在另一台机器或服务器上吗？
可以。服务端是单个 Go 二进制，监听 tcp:// 时默认启用 TLS 1.3，并打印一条包含地址、指纹与 token 的连接串；桌面端整条粘贴到「设置 → 服务端连接」即可。多台设备可各用一条连接串，token 在浏览器 /admin/ 按需生成或撤销，也可用 --rotate-token 立即失效全部旧 token。
支持哪些操作系统？
桌面端支持 Windows 10 / 11（x64）、macOS（Apple Silicon）以及 Linux（deb / AppImage）。服务端是单个 Go 二进制，同样覆盖三大平台，也可以只部署在局域网或远端服务器上。
桌面上看到的和仓库里的是同一套东西吗？
是。桌面端源码在 desktop/，服务端与 CLI 在仓库根目录的 internal/；桌面端不打包服务端，两者独立构建、独立升级。
